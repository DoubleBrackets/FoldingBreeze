# Folding Breeze

[![Unity-Release-Builder](https://github.com/DoubleBrackets/FoldingBreeze/actions/workflows/unity-release-builder.yml/badge.svg)](https://github.com/DoubleBrackets/FoldingBreeze/actions/workflows/unity-release-builder.yml)

Alternative control game about flying, hand fans, and the feel of wind.

Designed to be played with a custom hand fan and box fan pairing.

## Builds

Builds are playable at https://doublebrackets.itch.io/folding-breeze

### Software Libraries Used

Programs
- Unity 6000.3.7f1
- FMOD 2.03

Arduino Libraries (Required to compile sketches)
- https://github.com/adafruit/Adafruit_BNO08x (gyro sensor library)
  - https://docs.arduino.cc/libraries/adafruit-bno08x/


3P Unity Packages
- [NaughtyAttributes](https://github.com/dbrizov/NaughtyAttributes)
- [UniTask](https://github.com/Cysharp/UniTask)
